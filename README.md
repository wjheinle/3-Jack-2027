# 3 Jack

2027 3-Jack Invitational/Cup, Scottsdale AZ, May 29 to June 4, 2027.
Countdown, golf, flights, house, shared expenses and grocery list.

Node/Express with a JSON file store. Set the Railway volume mount path to `/data` (or set `DATA_DIR`).
Check `/api/health` after deploy: `usingFallback` must be `false`.
